Neste projeto **bem simples** o jogo de pedra, papel e tesoura acontece dentro do aplicativo de mensagens. Para jogar é preciso ler o código quadrado que aparece no terminal — e esse código pode ser exibido no navegador se você incluir um framework web no projeto.

Há uma gravação da demonstração.

Também publiquei uma postagem sobre o projeto numa rede profissional.

A ordem dos passos importa: nao pule a preparacao do ambiente.
